# Matchning

Kopplingen mellan [användningsfall](../10-anvandningsfall/) och
[tekniker](../20-tekniker/). Det är här värdet ligger — fel teknik på rätt problem
ser ut som att AI inte fungerar.

| Fil | Vad det är |
|---|---|
| [matris.md](matris.md) | Vad som faktiskt provats, och vad som fungerade |
| [beslutsguide.md](beslutsguide.md) | Frågor att gå igenom när något nytt kommer upp |

## Skillnaden mellan dem

**Matrisen** svarar på "har någon provat det här?". Den fylls bara på med rader som
bygger på ett genomfört experiment.

**Beslutsguiden** svarar på "vad borde vi prova?". Den bygger på resonemang och
tumregler, och ska ifrågasättas allt eftersom matrisen växer.

Håll isär dem. Blandas gissningar in i matrisen blir den en sammanställning av våra
förutfattade meningar, med ett trovärdigt utseende.
