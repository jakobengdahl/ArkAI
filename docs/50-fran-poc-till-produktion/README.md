# Från PoC till produktion

Vad som krävs för att gå från något som fungerar till något någon kan förlita sig på.

Det här är en av de två frågor labbet finns för att besvara — den andra är vilken
teknik som passar vilket problem. Skillnaden är att den här frågan sällan är teknisk.

| Fil | Vad det är |
|---|---|
| [checklista.md](checklista.md) | Frågor att besvara innan pilot, och innan produktion |
| [styrning-och-risk.md](styrning-och-risk.md) | Vad som behöver klaras ut, och var det brukar gå snett |
| [kostnad-och-drift.md](kostnad-och-drift.md) | De fyra kostnaderna, varav två aldrig räknas |

Se även [mognadstrappan](../00-oversikt/mognadstrappa.md) för vad stegen betyder.

## Hur materialet är tänkt att användas

Inte som en grind. Som en uppsättning frågor som annars ställs för sent — ofta av
någon annan än den som byggde, och ofta när det redan är dyrt att svara.

Gå igenom checklistan och skriv ner vad ni **inte** kan bocka av. Den listan är
resultatet. Det som saknas är antingen arbete som återstår eller en medveten risk;
båda går bra, men att inte veta vilket gör det inte.
